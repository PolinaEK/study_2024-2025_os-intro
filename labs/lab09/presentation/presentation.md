## Цель работы

Освоение основных возможностей командной оболочки Midnight Commander. Приобретение навыков практической работы по просмотру каталогов и файлов; манипуляций с ними.

## Изучите информацию о mc, вызвав в командной строке man mc.


![Изучаем и запускаем mc](image/1.png){#fig:001 width=70%}

## Используя возможности подменю Файл , выполните:
– просмотр содержимого текстового файла;
– редактирование содержимого текстового файла (без сохранения результатов
редактирования);
– создание каталога

![Создаем каталог](image/2.png){#fig:002 width=50%}

## Копирование в файлов в созданный каталог

![Копируем файлы в каталог](image/3.png){#fig:003 width=70%}

## С помощью соответствующих средств подменю Команда осуществите:
– поиск в файловой системе файла с заданными условиями (например, файла
с расширением .c или .cpp, содержащего строку main)

![Осуществляем поиск файлов](image/4.png){#fig:004 width=50%}


## Задание по встроенному редактору mc

1. Создайте текстовой файл text.txt.
2. Откройте этот файл с помощью встроенного в mc редактора.
3. Вставьте в открытый файл небольшой фрагмент текста, скопированный из любого
другого файла или Интернета.
Перейдите в начало файла (нажав комбинацию клавиш) и напишите некоторый
текст

![Редактируем файл](image/5.png){#fig:005 width=40%}
